Plain Sight

**Plain Sight** helps make long privacy policies easier to scan. Paste policy text to get a brief with excerpts that may relate to data collection, usage, sharing, retention, and user choices.

## Live site

After publishing this repository with GitHub Pages, add the site URL here. If your GitHub username is `shashwatshukla3291` and the repository is named `plain-sight`, the URL will be:

`https://shashwatshukla3291.github.io/plain-sight/`

## Features

- Scans pasted text for five common privacy topics
- Shows matching policy excerpts alongside each topic
- Includes fictional sample policies to try
- Runs entirely in the browser; pasted text is not uploaded or saved
- Responsive layout for desktop and mobile

## Built with

HTML, CSS, and JavaScript.

## Important note

This is a reading aid, not legal advice or an AI review. It uses a simple keyword checklist, so it may miss context, use different wording than the checklist expects, or fail to identify important terms. Check the original policy before making a decision.
